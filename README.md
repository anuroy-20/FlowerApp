A simple and clean Android application built with Kotlin and Jetpack Compose that displays a collection of flowers and provides detailed information for each flower.

The app demonstrates modern Android development concepts including Jetpack Compose, MVVM architecture, ViewModel, LiveData, and Navigation.

 Overview

FlowerApp allows users to:

- Browse a list of flowers
- Select a flower from the list
- View detailed information about the selected flower
- Navigate between the flower list and detail screens
- Experience a modern declarative UI using Jetpack Compose
- Features
Flower Listing

The home screen displays flowers in a clean, scrollable list.

Each flower item can display information such as:

Flower name
Flower image
Short description

Flower Details

When the user clicks on a flower, the app navigates to a detail screen showing additional information about the selected flower.

The details screen can include:

Flower name
Image
Description
Additional flower information
